# CodeStyle — проверка стиля кода C/C++ для Visual Studio Code

**Автор:** <Щуко Елизавета Антоновна>, группа <М3110>
**Репозиторий:** <https://github.com/LizaSchuko/CodeStyleCPP>
**Идентификатор расширения:** `liza2.codestylelinter` · версия 1.0.0

## Описание

**CodeStyle** — расширение (плагин) для Visual Studio Code, которое автоматически проверяет
исходный код на C и C++ на соответствие учебному стилю оформления, наглядно показывает нарушения
в редакторе, помогает безопасно их исправить, считает оценку стиля в процентах и формирует отчёт.
Расширение **не меняет логику программы** — только оформление.

## Возможности

| Возможность | Как пользоваться |
|---|---|
| Автоматическая проверка при открытии файла и при каждом изменении текста | Работает сама |
| Подчёркивание нарушения (только имя, оператор, отступ или ключевое слово) | Видно в редакторе |
| Описание нарушения во всплывающей подсказке и в панели **Problems** | Наведите мышь / `Ctrl+Shift+M` |
| Быстрые исправления: «Исправить отступ», «Поставить пробелы», «Добавить фигурные скобки», «Переименовать «…» в «…»» | `Ctrl+.` на подчёркнутом месте |
| Привести файл в порядок: пробелы, скобки, отступы, затем переименование имён | `Ctrl+Alt+L` |
| Проверка без изменения файла (количество нарушений + открытие панели Problems) | `Ctrl+Alt+K` |
| Оценка стиля в процентах (постоянно в правом нижнем углу, по щелчку — подробности) | `Ctrl+Alt+S` |
| Отчёт в формате Markdown (таблица нарушений, оценка) | `Ctrl+Alt+R` |
| Переименование переменной в snake_case с учётом области видимости | Команда «CodeStyle: Переименовать переменную в snake_case» |

## Что проверяется

| Правило | Что проверяется |
|---|---|
| `naming` | Переменные и параметры — `snake_case`; функции и типы — `PascalCase`; константы — `kPascalCase` |
| `indentation` | Допустимы либо табуляция, либо 4 пробела на уровень; нарушение — смесь табов и пробелов или отступ из пробелов, не кратный 4 |
| `spacing` | Пробелы вокруг `=`, `+=`, `==`, `&&`, `\|\|`, `+`, `-`, `/`, `%` и др.; пробел после запятой и после `;` в заголовке `for` |
| `braces` | У `if`, `else`, `for`, `while` тело в `{ }` (короткая запись в одну строку допустима); у `switch` блок `{ }` обязателен |

## Требования

- Visual Studio Code 1.80 или новее
- Расширение **C/C++** от Microsoft (нужно только для переименования имён)


## Структура проекта

```
codestylelinter/
├── docs/                    Документация проекта
│   └── documentation.md     Общее описание решения, описание каждой функции с примерами вызова и история изменений проекта. 
├── node_modules/            Установленные библиотеки (создаётся командой `npm install`, в репозиторий не попадает)
├── out/                     Результат сборки: JavaScript, который получается из `src/` командой `npm run compile`. 
│   ├── checks.js
│   └── extension.js
├── src/                     Исходный код расширения на TypeScript
│   ├── checks.ts            Логика проверок стиля: отступы, пробелы, фигурные скобки, имена; расчёт оценки; применение исправлений. От VS Code не зависит: получает текст, возвращает список нарушений
│   └── extension.ts         Подключение к VS Code: подчёркивание нарушений, панель Problems, быстрые исправления (`Ctrl+.`), команды и горячие клавиши и тд.
├── package-lock.json        Точные версии установленных библиотек (создаётся автоматически)
├── package.json             Декларация расширения: название, версия, издатель, список команд, горячие клавиши, события запуска, зависимости для разработки и скрипт сборки
├── README.md                Настройки компилятора TypeScript: откуда брать код (`src`) и куда класть результат (`out`)
├── codestylelinter-1.0.0    Файл для импортирования расширения на компьютер
└── tsconfig.json            Описание проекта
```
