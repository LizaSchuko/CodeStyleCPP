# CodeStyle

### 1. Общее описание решения

**CodeStyle** — расширение (плагин) для Visual Studio Code, которое проверяет код на C/C++ на соответствие учебному стилю оформления, подчёркивает нарушения, предлагает безопасные исправления, считает оценку стиля в процентах и формирует отчёт. Логику программы пользователя расширение не меняет.

Проект состоит из двух файлов с кодом:
* `src/checks.ts` — «мозг»: получает текст программы и возвращает список нарушений. С VS Code не связан.
* `src/extension.ts` — «проводка»: показывает нарушения в VS Code (подчёркивания, панель Problems, быстрые исправления, команды, строка состояния).

Служебные файлы: `package.json` (манифест: команды и горячие клавиши) и `tsconfig.json` (настройки компиляции).

Как это работает:
1. VS Code включает расширение, когда пользователь открывает файл C или C++.
2. При открытии файла и при каждом изменении текста вызывается `check(text)`.
3. Комментарии, содержимое строк в кавычках и директивы `#...` «закрашиваются» пробелами — их не проверяют.
4. Четыре проверки — отступы, пробелы, скобки, имена — ищут нарушения и возвращают их в виде списка `Issue`.
5. `extension.ts` превращает `Issue` в подчёркивания, пункты быстрых исправлений и оценку в строке состояния.

Главная структура данных — `Issue` (одно нарушение):

| Поле | Тип | Смысл |
| :--- | :--- | :--- |
| `line` | `number` | номер строки (с нуля) |
| `start`, `end` | `number` | какую часть строки подчёркивать |
| `rule` | `string` | правило: `naming`, `indentation`, `spacing`, `braces` |
| `message` | `string` | описание нарушения |
| `edits` | `Edit[]` | правки текста для исправления (необязательно) |
| `newName` | `string` | новое имя для переименования (необязательно) |

Горячие клавиши: `Ctrl+Alt+L` — привести файл в порядок; `Ctrl+Alt+Shift+L` — проверить без изменений; `Ctrl+Alt+S` — оценка; `Ctrl+Alt+R` — отчёт; `Ctrl+.` — быстрое исправление.

### 2. Описание каждой функции с примерами вызовов

Номера строк и символов везде считаются с нуля.

#### Файл `src/checks.ts`

##### Функция `maskLines(lines)`
Принимает массив строк файла (`string[]`), возвращает массив строк (`string[]`), в которых комментарии, содержимое строк в кавычках и директивы `#` заменены пробелами. Длина строк не меняется.

* **Пример вызова в коде:**
```ts
console.log(maskLines(['s = "a=b";']));   // Выведет: [ 's = "   ";' ]
```

##### Функция `findClose(s, open)`
Принимает строку (`string`) и позицию открывающей скобки `(` (`number`), возвращает позицию парной закрывающей скобки (`number`) или `-1`, если на этой строке скобка не закрыта.

* **Пример вызова в коде:**
```ts
console.log(findClose('if (a) b;', 3));   // Выведет: 5
console.log(findClose('if (a &&', 3));    // Выведет: -1
```

##### Функция `nextCode(masked, n)`
Принимает «закрашенные» строки (`string[]`) и номер строки (`number`), возвращает номер ближайшей ниже строки, где есть код (`number`), или `-1`.

* **Пример вызова в коде:**
```ts
console.log(nextCode(['if (x)', '', '  return;'], 0));   // Выведет: 2
```

##### Функция `fixIndent(ws)`
Принимает отступ строки (`string`: пробелы и табуляции в начале строки), возвращает исправленный отступ (`string`): только табы или только пробелы, кратно 4. Повторный вызов результат не меняет.

* **Пример вызова в коде:**
```ts
console.log(JSON.stringify(fixIndent('      ')));   // Выведет: "        "  (6 пробелов → 8)
console.log(JSON.stringify(fixIndent('\t ')));      // Выведет: "\t"
```

##### Функция `checkIndent(lines, masked, issues)`
Принимает настоящие строки файла (`string[]`), «закрашенные» строки (`string[]`) и общий список нарушений (`Issue[]`). Ничего не возвращает (`void`), а дописывает в список нарушения отступов: смесь табуляций и пробелов или отступ из пробелов, не кратный 4.

* **Пример вызова в коде:**
```ts
const issues: Issue[] = [];
const text = ['int main() {', '   int a;', '}'];
checkIndent(text, text, issues);
console.log(issues[0].line, issues[0].message);
// Выведет: 1 Отступ из пробелов должен быть кратен 4
```

##### Функция `checkSpacing(masked, issues)`
Принимает «закрашенные» строки (`string[]`) и список нарушений (`Issue[]`). Ничего не возвращает (`void`), а дописывает нарушения пробелов: вокруг операторов, после запятой и после `;` в заголовке `for`. Внутри использует вспомогательную функцию `add(start, end, message, text)`, которая добавляет одно нарушение и правку для его исправления.

* **Пример вызова в коде:**
```ts
const issues: Issue[] = [];
checkSpacing(['int a=5;'], issues);
console.log(issues[0].message);   // Выведет: Нужны пробелы вокруг «=»
```

##### Функция `checkBraces(lines, masked, issues)`
Принимает настоящие строки (`string[]`), «закрашенные» строки (`string[]`) и список нарушений (`Issue[]`). Ничего не возвращает (`void`), а дописывает нарушения: тело `if`, `else`, `for`, `while` на следующей строке без `{ }` и `switch` без блока. Короткая запись в одну строку допустима. Автоисправление добавляется, только если тело — один простой оператор.

* **Пример вызова в коде:**
```ts
const issues: Issue[] = [];
const text = ['if (x)', '    return 1;'];
checkBraces(text, text, issues);
console.log(issues[0].message);   // Выведет: Тело «if» должно быть заключено в { }
```

##### Функция `words(name)`
Принимает имя (`string`), возвращает массив слов маленькими буквами (`string[]`).

* **Пример вызова в коде:**
```ts
console.log(words('userName'));    // Выведет: [ 'user', 'name' ]
console.log(words('MAX_COUNT'));   // Выведет: [ 'max', 'count' ]
```

##### Функция `pascal(name)`
Принимает имя (`string`), возвращает его в стиле PascalCase (`string`).

* **Пример вызова в коде:**
```ts
console.log(pascal('find_element'));   // Выведет: FindElement
```

##### Функция `toSnake(name)`
Принимает имя (`string`), возвращает его в стиле snake_case (`string`). Завершающий `_` (поле класса) сохраняется.

* **Пример вызова в коде:**
```ts
console.log(toSnake('userName'));   // Выведет: user_name
console.log(toSnake('Value_'));     // Выведет: value_
```

##### Функция `checkName(issues, line, col, name, kind)`
Принимает список нарушений (`Issue[]`), номер строки (`number`), позицию начала имени (`number`), само имя (`string`) и вид имени (`'variable' | 'function' | 'type' | 'constant'`). Ничего не возвращает (`void`); если имя написано неправильно, добавляет нарушение с предложенным новым именем. Ключевые слова и имена, начинающиеся с `_`, пропускаются.

* **Пример вызова в коде:**
```ts
const issues: Issue[] = [];
checkName(issues, 0, 4, 'userName', 'variable');
console.log(issues[0].newName);   // Выведет: user_name
```

##### Функция `splitParams(s)`
Принимает текст между скобками функции (`string`), возвращает список параметров (`{text: string, offset: number}[]`). Запятые внутри `<>` и `()` разделителями не считаются.

* **Пример вызова в коде:**
```ts
console.log(splitParams('int a, int b'));
// Выведет: [ { text: 'int a', offset: 0 }, { text: ' int b', offset: 6 } ]
```

##### Функция `checkNaming(masked, issues)`
Принимает «закрашенные» строки (`string[]`) и список нарушений (`Issue[]`). Ничего не возвращает (`void`), а дописывает нарушения имён: типов (`class`, `struct`, `enum`, `using`, `typedef`), функций и их параметров, переменных и констант. Если случай нельзя определить надёжно, строка пропускается. Внутри использует вспомогательную функцию `withoutDefault(s)`, которая отбрасывает значение параметра по умолчанию (`'int a = 5'` → `'int a'`).

* **Пример вызова в коде:**
```ts
const issues: Issue[] = [];
checkNaming(['int calculateSum(int a) {'], issues);
console.log(issues[0].message);
// Выведет: Имя «calculateSum» должно быть в стиле PascalCase (например, CalculateSum)
```

##### Функция `check(text)`
Главная функция проверки. Принимает полный текст файла (`string`), возвращает список нарушений (`Issue[]`), отсортированный по номеру строки.

* **Пример вызова в коде:**
```ts
const issues = check('int main() {\n   int a=1;\n}');
console.log(issues.map(i => i.rule));   // Выведет: [ 'indentation', 'spacing' ]
```

##### Функция `applyEdits(text, edits)`
Принимает текст (`string`) и список правок (`Edit[]`), возвращает новый текст с применёнными правками (`string`). Правки, пересекающиеся с уже применёнными, пропускаются.

* **Пример вызова в коде:**
```ts
console.log(applyEdits('a=1;', [{ line: 0, start: 1, end: 2, text: ' = ' }]));
// Выведет: a = 1;
```

##### Функция `score(violations, lineCount)`
Принимает количество нарушений (`number`) и количество строк (`number`), возвращает оценку стиля от 0 до 100 (`number`) по формуле `max(0, round(100 − нарушения / строки × 100))`. Для файла из 0 строк — 100.

* **Пример вызова в коде:**
```ts
console.log(score(5, 50));    // Выведет: 90
console.log(score(80, 50));   // Выведет: 0
console.log(score(0, 0));     // Выведет: 100
```

#### Файл `src/extension.ts`

##### Функция `isCpp(doc)`
Принимает документ редактора (`vscode.TextDocument`), возвращает `true` (`boolean`), если это файл C или C++.

* **Пример вызова в коде:**
```ts
const ok = isCpp(vscode.window.activeTextEditor!.document);
console.log(ok);   // Выведет: true  (для main.cpp)
```

##### Функция `activeCpp()`
Ничего не принимает. Возвращает активный редактор (`vscode.TextEditor`), если в нём открыт файл C/C++, иначе `undefined`.

* **Пример вызова в коде:**
```ts
const ed = activeCpp();
if (!ed) return;   // команда работает только для C/C++
```

##### Функция `analyze(doc)`
Принимает документ (`vscode.TextDocument`), возвращает объект `{ issues: Issue[], lines: number, percent: number }`: нарушения, количество строк и оценку в процентах.

* **Пример вызова в коде:**
```ts
const { issues, percent } = analyze(doc);
console.log(percent);   // Выведет, например: 85
```

##### Функция `refresh(doc)`
Принимает документ (`vscode.TextDocument`). Ничего не возвращает (`void`): обновляет подчёркивания, панель Problems и процент в строке состояния. Вызывается при открытии файла и после каждого изменения текста.

* **Пример вызова в коде:**
```ts
refresh(vscode.window.activeTextEditor!.document);
```

##### Функция `rename(uri, pos, newName)`
Принимает адрес файла (`vscode.Uri`), позицию имени (`vscode.Position`) и новое имя (`string`). Возвращает `Promise<boolean>`: `true`, если языковой сервер C/C++ выполнил переименование с учётом областей видимости, и `false`, если сервера нет или он отказал.

* **Пример вызова в коде:**
```ts
const ok = await rename(doc.uri, new vscode.Position(3, 8), 'user_name');
console.log(ok);   // Выведет: true
```

##### Метод `Fixer.provideCodeActions(doc, _range, ctx)`
Принимает документ (`vscode.TextDocument`), выделение (`vscode.Range`, не используется) и контекст с предупреждениями под курсором (`vscode.CodeActionContext`). Возвращает пункты меню быстрых исправлений (`vscode.CodeAction[]`). VS Code вызывает метод сам при нажатии `Ctrl+.`.

* **Пример вызова в коде:**
```ts
vscode.languages.registerCodeActionsProvider(['c', 'cpp'], new Fixer());
```

##### Функция `activate(ctx)`
Принимает контекст расширения (`vscode.ExtensionContext`). Ничего не возвращает (`void`): регистрирует команды и подписки на события редактора. Внутри использует вспомогательную функцию `reg(id, fn)` для регистрации одной команды. VS Code вызывает `activate` сам при открытии файла C/C++.

* **Пример вызова в коде:**
```ts
export function activate(ctx: vscode.ExtensionContext) {
  reg('codestyle.score', () => info('Привет'));
}
```

##### Функция `deactivate()`
Ничего не принимает и ничего не возвращает (`void`). Вызывается VS Code при выключении расширения.

* **Пример вызова в коде:**
```ts
deactivate();   // вызывается самим VS Code
```

##### Команды (обработчики внутри `activate`)
Запускаются горячими клавишами, из палитры команд (`Ctrl+Shift+P`) или так: `await vscode.commands.executeCommand('<команда>')`.

| Команда | Что принимает | Что возвращает | Что делает |
| :--- | :--- | :--- | :--- |
| `codestyle.format` (`Ctrl+Alt+L`) | ничего | `Promise<void>` | исправляет пробелы, скобки и отступы, затем переименовывает имена через языковой сервер |
| `codestyle.check` (`Ctrl+Alt+K`) | ничего | `Promise<void>` | проверяет без изменений, показывает число нарушений, открывает панель Problems |
| `codestyle.score` (`Ctrl+Alt+S`) | ничего | `void` | показывает оценку стиля |
| `codestyle.report` (`Ctrl+Alt+R`) | ничего | `Promise<void>` | сохраняет Markdown-отчёт в выбранное место |
| `codestyle.rename` | ничего | `Promise<void>` | переименовывает слово под курсором в snake_case |
| `codestyle.renameAt` (внутренняя) | `uri` (`vscode.Uri`), `pos` (`vscode.Position`), `name` (`string`) | `Promise<void>` | переименование из меню Quick Fix |
